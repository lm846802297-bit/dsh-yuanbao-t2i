# 提示词模板

元宝（混元 Hy Image）对**中文长句**的响应比逗号关键词堆砌更好用，实测有效结构是：

```
主体 + 动作/状态 + 环境 + 光影 + 风格 + 构图/比例
```

一次调用固定出 4 张，所以**写细一点更划算**——4 张里总能挑出可用的。

## 1. 场景（BG / 背景大图）

```
一座哥特式教堂，雨夜，雾气弥漫，石墙湿润反光，远处有一盏街灯，
电影级冷色调，油画质感，提示词画面里不要出现文字，横构图 16:9
```

```
废弃的天文台内部，生锈的黄铜望远镜指向破损的穹顶，月光从裂缝照下来，
尘埃在光柱里漂浮，暗调，写实 CG，横构图
```

## 2. 角色立绘

```
一位穿黑色长裙的银发少女，站在雾中的石阶上，侧身回头，眼神冷淡，
背后是哥特式拱窗，冷色逆光，二次元厚涂，全身像，纯色背景便于抠图，竖构图
```

要点：**「纯色背景」**或**「简洁背景」**能显著提高抠图成功率；想要立绘就写「全身像」。

## 3. CG（带叙事的画面）

```
月夜的哥特式钟楼顶部，一位长着黑色羽翼的少女驻足在塔尖，低头看向城市，
满月当空，云层被月光穿透，教堂尖顶与远处屋群层层叠叠，深蓝与银白色调，
精致插画，竖构图
```

## 4. 水彩 / 纸质手感

```
水彩静物：石墙边的落叶、青苔与铁艺围栏，湿画法，纸纹明显，留白自然，
浅绿与赭石色，手绘感
```

## 5. 图标 / UI 素材

```
一个简洁的线性图标：羽毛与钟面组合，单色描边，留白充足，扁平风格，正方形
```

## 实用技巧

| 想要 | 加什么词 |
| --- | --- |
| 竖图 / 立绘 | `竖构图`、`全身像` |
| 横图 / 背景 | `横构图`、`16:9` |
| 便于抠图 | `纯色背景`、`简洁背景` |
| 更稳的质感 | `油画质感`、`厚涂`、`水彩纸纹`、`写实 CG` |
| 避免出现乱码文字 | `画面里不要出现文字`（仍然无法 100% 保证） |

⛔ 一次只改一个变量：想对比风格时同一段提示词只替换风格词，否则 4 张差异来源不可归因。
